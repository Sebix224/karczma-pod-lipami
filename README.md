# Strona Karczmy Pod Lipami – wersja do akceptacji

Strona Karczmy Pod Lipami (Ustroń, ul. Szpitalna 5): menu z cenami, zamówienia na wynos (odbiór osobisty), rezerwacja stolika, galeria dań, godziny otwarcia i mapa dojazdu. Zamówienia i rezerwacje trafiają na e-mail karczmy przez FormSubmit.
