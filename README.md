# Strona Karczmy Pod Lipami – wersja do akceptacji

Strona Karczmy Pod Lipami (Ustroń, ul. Szpitalna 5): menu z cenami, zamówienia na wynos (odbiór osobisty), rezerwacja stolika, galeria dań, godziny otwarcia i mapa dojazdu. Zamówienia i rezerwacje przychodzą do karczmy SMS-em: strona przygotowuje treść, a klient wysyła SMS ze swojego telefonu na 787 081 383 (z komputera – prośba o telefon).
